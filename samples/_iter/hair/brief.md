## 2단계. 레퍼런스 3곳 (휴대폰 폭 캡처 `company/design/references/ref-hair-sheet.png`)
| 레퍼런스 | 시그니처 | 독창 포인트 |
|---|---|---|
| Parlour (parlourvt.com) | 사진 전면 + 큰 세리프 로고, 사진 아래 걸친 흰 예약 바, 위치·전화·영업시간 3칸이 바로 이어짐 | 사진 끝에 걸친 흰 예약 바 |
| Salon SCK (salonsck.com) | 맨 위 예약 띠, 숯색 머리글, 사진 위 세리프 이름 + 테두리 버튼, 서비스는 큰 사진 카드 + 세리프 이름 | 사진 카드 아래 세리프 한 단어 이름 |
| Kaleido Hair (11-16 카드, 이번엔 로봇 확인으로 캡처 불가) | 검은 머리띠, 세리프 대문자 제목, 흰↔크림 띠, 짙은 띠 위 큰 문장 | 짙은 띠 위 큰 문장 한 줄 |
- 제외: Le Petit Salon(lpslyon.fr)은 미용실이 아니라 공연장이라 뺌.
- **공통 규칙**: 첫 화면 = 진짜 머리 사진 + 예약 버튼 / 첫 화면 바로 아래 실용 정보(시간·위치·전화) / 세리프 제목 + 산세리프 본문 / 그레이지·숯색, 강조색 거의 없음 / 버튼은 각지거나 얇은 테두리
- 가져온 독창 포인트 1개: Parlour의 '사진 끝에 걸친 예약 바'(A·B안), C안은 Kaleido의 '짙은 띠 위 큰 문장'

## 4단계. 첫 화면 3안 → 비교표 (아래에 점수)

### 1바퀴 (round1.png) — 점수: 목적 / 레퍼런스 규칙 / 3초 행동 / 잡지형 평균 아님 / 375 가독 (각 5점)
| 안 | 점수 | 이유 |
|---|---|---|
| A 레퍼런스 충실 | 4·5·5·2·5 = **21** | 사진 전면 + 걸친 예약 바 + 정보 3칸. 깔끔하지만 흔한 미용실 화면(평균에 가까움) |
| B 모티프 크게 | 5·3·4·5·4 = **21** | 결 곡선이 사진 속 머리결로 이어져 가장 이 가게다움. 정보가 한 줄로 눌림 |
| C 배치 뒤집기 | 4·3·4·4·4 = **19** | 글자 먼저 숯색 띠. 사진 띠가 잘려 보이고 첫 화면에 정보 없음 |
→ 동점 중 '평균 탈출'이 목적이라 **B 선택**, A의 강점(정보 3칸)을 2바퀴에서 더함.

### 2바퀴 (round2.png)
| 안 | 점수 | 이유 |
|---|---|---|
| B1 = B + 정보 3칸 | 5·4·5·5·4 = **23** | 첫 화면 안에 목적·결 3단계·예약·영업/주차/전화가 다 보임 |
| B2 = 사진 전체 폭 + 곡선을 사진 위로 | 3·4·4·3·4 = **18** | 흰 곡선이 머리 위에서 긁힌 자국처럼 보임(손상 연상 → 목적과 반대). 버튼이 아래로 밀림 |
→ **B1 확정.** 배운 점: 모티프는 '배경에서 사진으로 이어질 때' 살고, 사진 위에 얹으면 목적과 반대 인상을 줄 수 있다.
